# Inspect

Read the PRD and target monorepo without modifying application code. Detect Django,
DRF, settings, domain apps, user model, database, cache, tasks, API conventions,
tests, Docker, CI, and migrations. Store findings under target `.ai/discovery/`.
For persistence, record PostgreSQL version/driver, connection ownership, migration head/
branches, domain tables, constraints, indexes, transaction boundaries, hot query shapes,
query budgets, pagination, and versioned URL/OpenAPI conventions.
