# Post-write

Check changed paths and generated structure; run the smallest affected Django checks
and tests. For database/API changes also check PostgreSQL connectivity, migration drift,
schema objects, query budgets, URL resolution, and OpenAPI drift. Store concise evidence
and release the implementer lease.
Reject source-policy violations and incomplete activated domain capability groups.
Reject vague non-PRD app names, generic serializer direction files, a monolithic API view module,
empty responsibility packages, and files beyond the structure contract's split threshold.
