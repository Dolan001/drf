# Inspect Django target

Inspect `manage.py`, settings, installed apps, root URLs, package manifests, domain
apps, migrations, authentication, OpenAPI, and tests. Sample representative files;
do not read every model or view. Record confidence, deviations from
`rules/project-structure.md`, and brownfield conventions that must be preserved.
